# Catchspend Marketing Website

The landing page and feature showcase for the Catchspend expense tracker app — an on-device SMS-based transaction extraction tool.

## What's in here

- **index.html** — Home page with hero section and feature overview
- **Features.html** — Detailed feature breakdown with screenshots
- **Privacy.html** — Privacy policy
- **_ds/** — Design system (Organic theme) with CSS tokens and component styles
- **ref/** — Images, app icon, screenshots
- **support.js** — Claude Design runtime (auto-generated, do not edit)

## Running locally

No build step required. Open `index.html` in a browser to preview. All links and assets are relative, so everything works from the filesystem.

## Email capture setup

The site uses [Formspree](https://formspree.io) to collect pre-launch signup emails. The form endpoint is configured in the HTML (xppaaogo).

When users submit an email:
1. Formspree collects it and sends a confirmation
2. You receive an email notification
3. Emails are stored in your Formspree dashboard

No backend or database setup needed — Formspree handles everything.

## Deploying to GitHub Pages

1. **Create a new repo** called `catchspend-marketing` (or similar)
2. **Push these files** to the `main` branch
3. **Enable Pages** in repo settings → Settings → Pages → Source: Deploy from branch → `main` branch, root folder
4. Your site will be live at `https://yourusername.github.io/catchspend-marketing`

All links and assets are relative, so they'll work on Pages without modification.

## Design system

The Organic design system lives in `_ds/organic-*/`:

- **styles.css** — CSS variables for colors, typography, spacing, radii, shadows
- **readme.md** — Full design guidelines and component patterns

Never hard-code colors or sizes. Use CSS variables instead:

```css
color: var(--color-accent);
background: var(--color-accent-100);
border-radius: var(--radius-lg);
box-shadow: var(--shadow-md);
```

## Page structure

Each `.html` file is self-contained (no dependencies on others). Forms are wired to Formspree endpoints using the form ID `xppaaogo`.

### Form locations
- **Home.html (now index.html)** — Hero CTA + bottom section
- **Features.html** — Bottom section

Forms capture email only and submit directly to Formspree.

## Customization

### Change branding
- Update icon in `ref/icon.png` (keep at ~100px square)
- Update app name "Catchspend" in the nav
- Update contact email in footer (`appdev.nkc@gmail.com`)

### Change colors
Edit the CSS variables at the top of `_ds/organic-*/styles.css`:
- `--color-accent` (primary color)
- `--color-accent-2` (secondary color)
- `--color-bg` (background)
- `--color-text` (foreground)

All tonal ramps regenerate automatically.

### Update copy
HTML is plain text. Edit headlines, body copy, and button labels directly in the `.html` files. No templating or compilation step.

## Common tasks

**Add a new section** — Copy an existing `<section>` block and modify the content.

**Change the screenshot** — Replace image in `ref/` and update the `src` attribute in the corresponding `.html` file.

**Update the Formspree endpoint** — If you create a new form, replace `f/xppaaogo` with your new form ID in the `<form action>` attributes.

**Add a new page** — Copy an existing `.html`, update the nav links in all files to point to it, and add it to the GitHub repo.

## What's off-limits

- Do not edit `support.js` — it's auto-generated by Claude Design
- Do not edit files in `_ds/` unless you fully understand the design system tokens
- Do not use colors, fonts, or spacing outside the design system variables

## Troubleshooting

**Forms not working?**
- Check the `<form action>` URL matches your Formspree endpoint
- Test with `curl -X POST https://formspree.io/f/xppaaogo -d "email=test@example.com"`

**Pages not loading?**
- Verify all relative paths are correct (especially `_ds/`, `ref/`, `support.js`)
- Ensure you're running from the repo root

**Styling broken?**
- Check that `_ds/*/styles.css` is loading (open DevTools → Network tab)
- Verify no inline styles conflict with design system variables
